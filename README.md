# Élan Fashion Boutique

A fictional, responsive fashion boutique website created as a portfolio demonstration with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a modern browser. No build step or package installation is required.

## Features

- Responsive luxury fashion editorial with a charcoal-and-burgundy palette, full-bleed hero, asymmetric product collections, boutique story, featured collection, testimonials, and contact details
- Accessible mobile navigation, smooth in-page links, reduced-motion support, and scroll reveal effects
- Functional demo shopping bag with add/remove items, subtotal, and checkout notice
- Fashion photography from Unsplash and typography from Google Fonts

## Demo notes

Boutique details, prices, and testimonials are fictional. Product bag and checkout interactions are front-end demonstrations and do not process or store orders. Replace sample contact details and connect a real commerce platform before using this for a business.
